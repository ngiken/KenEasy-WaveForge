i 格式、视频导出与隐私说明
  • 100% 隐私安全：全流程使用浏览器 Web Audio API 与 Canvas 离线帧合成，音频与画面绝不上云。
  • 多格式与示例曲目：支持 MP3、WAV、FLAC、M4A、OGG 等格式；若手头暂无音频，可一键点击「试听示例曲目」瞬间体验。
  • 画幅与社交平台适配：提供 9:16（抖音/小红书/Shorts）、16:9（B站/YouTube）与 1:1（唱片封面/动态Feed），按发布目标一键切换。
  • 拟物黑胶与高阶动效：黑胶唱片模式搭载拟物铝合金唱针臂与同心微纹路；波形支持贝塞尔平滑渲染与自适应频谱柱。
  • 自由区间截取：支持双向手柄自由拖动，直接截取高潮 Hook 片段导出，省去第三方剪辑软件二次裁剪。
  • 极速硬件加速导出：通过原生 MediaRecorder 流式合成，画中画实时监看录制状态，完成后秒级保存为标准 MP4/WebM 视频。
